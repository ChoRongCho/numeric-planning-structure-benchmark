# 연구 가설 후보

아직 중심 연구 문제로 확정되지 않은 failure mechanism 후보를 보관한다. 각 가설은
예상 관찰과 반증 조건을 갖춰야 하며, timeout 수치만으로 승격하지 않는다.

## H1. 자원 경쟁 정보의 약화

### 가설

Relaxation이 여러 goal/action이 같은 numeric resource를 경쟁한다는 사실을 약하게
표현하여 필요한 자원량 또는 action cost를 과소평가한다.

### 예상 관찰

- 전체 demand가 같아도 공유 resource에 집중될수록 heuristic error가 커진다.
- slack이 줄어들수록 plateau와 expansion이 증가한다.
- resource competition을 제거한 대조군에서는 현상이 약해진다.

### 반증 조건

- 크기를 통제한 뒤 tightness/coupling 효과가 사라진다.
- heuristic ranking은 유지되고 grounding 또는 feasibility 검사 시간만 증가한다.

## H2. 객체 identity와 grouping의 붕괴

### 가설

총 numeric 값이 같은 상태라도 item별 weight, location, ownership, capacity 조합에 따라
실제 packing 가능성이 다르지만 relaxed estimate가 이를 충분히 구분하지 못한다.

### 예상 관찰

- 총 weight와 goal 수가 같은 서로 다른 grouping 문제에 동일하거나 가까운 `h`가
  부여되지만 실제 cost-to-go는 달라진다.
- capacity 경계에서 ranking reversal이 집중된다.
- 객체별 grouping 정보를 추가한 oracle estimate에서 reversal이 감소한다.

### 반증 조건

- 비교 heuristic이 이미 객체별 supporter와 capacity를 구분한다.
- grouping을 바꿔도 heuristic error와 expansion이 변하지 않는다.

## H3. Action repetition 근사의 오차

### 가설

반복 가능한 numeric action의 실행 횟수를 연속량, interval 또는 독립 subgoal로
근사하면서 정수 횟수와 다른 action과의 순서 제약이 손실된다.

### 예상 관찰

- threshold가 action effect의 배수에서 조금 벗어나는 경계에서 heuristic 값이 실제
  거리 변화를 따라가지 못한다.
- repetition-aware heuristic과 단순 interval heuristic의 차이가 해당 문제에서
  커진다.

### 반증 조건

- repetition을 제거한 문제에서도 같은 패턴이 나타난다.
- 반복 횟수를 정확히 반영해도 state ranking이 개선되지 않는다.

## H4. Helpful-action 추출의 병목

### 가설

Core heuristic 값보다 relaxed plan에서 뽑은 helpful/preferred action 집합이 실제로
필요한 우회 action을 반복해서 뒤로 미뤄 search를 악화시킨다.

### 예상 관찰

- 같은 heuristic에서 helpful-action pruning을 끄면 coverage 또는 expansion이
  개선되는 instance가 존재한다.
- 정답 경로의 다음 action이 helpful 집합에 들어가는 recall이 coupling 증가에 따라
  감소한다.

### 반증 조건

- helpful action을 꺼도 동일하게 악화된다.
- 모든 applicable action을 유지하는 fallback queue가 이미 문제를 제거한다.

## H5. Relaxed estimate와 실제 feasibility 검사의 간극

### 가설

Heuristic은 유망하다고 평가하지만 실제 successor 또는 partial plan은 numeric
constraint, LP 또는 SMT 검사에서 반복적으로 거부되어 탐색 노력이 낭비된다.

### 예상 관찰

- tightness/coupling과 infeasible candidate 비율이 함께 증가한다.
- heuristic 값은 좋아지지만 LP/SMT rejection 또는 dead-end가 늘어난다.
- feasibility-aware lower bound에서 잘못된 분기가 감소한다.

### 반증 조건

- feasibility rejection 이전에 grounding이나 heuristic 계산이 시간을 지배한다.
- rejected candidate 비율과 성능 사이에 일관된 관계가 없다.

## 문제 승격 규칙

가설은 다음이 준비됐을 때만 [01 연구 문제 정의](01_연구_문제_정의.md)의 중심 문제로
옮긴다.

- 조절 가능한 독립 변수
- 문제 크기와 다른 요인을 고정한 대조군
- 원인에 가까운 중간 지표
- 재현되는 planner/heuristic 범위
- 명시적인 반증 조건
- 지목한 정보만 복원하는 최소 oracle 또는 ablation

## 해결책 아이디어 보류 영역

아래 아이디어는 문제가 확인된 뒤에만 평가한다.

- capacity/grouping 정보를 반영하는 handcrafted heuristic
- interaction-aware preferred action 또는 fallback queue
- SLM/LLM을 이용한 soft guidance
- potential heuristic coefficient의 domain/instance transfer
- cost partitioning의 구조적 초기화 또는 근사

해결책이 흥미롭다는 이유로 연구 문제를 그 해결책에 맞춰 정의하지 않는다.
구체적인 후보 방법론과 검증 계획은
[수치 플래닝 휴리스틱 연구 방향](12_연구_방향/01_수치_플래닝_휴리스틱_연구_방향.md)에 분리한다.
