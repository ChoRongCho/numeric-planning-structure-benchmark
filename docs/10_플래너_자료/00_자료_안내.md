## 조사 범위와 한계

여기서 numeric planning은 좁은 의미의 sequential numeric PDDL뿐 아니라 다음을
모두 포함한다.

1. PDDL2.1 Level 2의 instantaneous numeric planning
2. Simple Numeric Planning(SNP)과 Linear Numeric Planning(LNP)
3. Durative action과 continuous linear effect를 갖는 temporal-numeric planning
4. Process/event/nonlinear dynamics를 포함하는 PDDL+
5. Numeric task를 SAT/SMT/OMT/MILP/CP로 변환하는 symbolic planning
6. Numeric task를 classical planning으로 변환하는 compilation

문헌에 이름이 등장한 모든 개인용·비공개 prototype까지 완전히 열거하는 것은
검증할 수 없다. 대신 공식 IPC 명단, 저자·기관 페이지, 논문 원문, 공식 또는
저자 공개 저장소를 교차 확인했다. "코드 있음"은 링크 존재를 의미하며, 현재
Ubuntu에서 바로 빌드된다는 의미는 아니다.

## 한눈에 보는 결론

### 지금 연구에 가장 먼저 확보할 실행기

| 우선 | Planner | 계열 | 이유 |
|---:|---|---|---|
| 1 | ENHSP / JPDDL+ | Forward heuristic search | 표현력이 넓고 `hadd`, `hmax`, subgoaling, helpful/jumping을 비교 가능 |
| 2 | Numeric Fast Downward / NLM-CutPlan | A*·GBFS + admissible numeric heuristics | LM-cut, operator counting, bounds, symmetry의 기준 구현 |
| 3 | PATTY | SMT symbolic pattern planning | Search 계열과 정반대인 강한 symbolic baseline |
| 4 | Panino | GBFS + partitioned numeric novelty | 2026 satisficing/agile 전체 우승 계열 |
| 5 | Count Downward | Numeric PDB/domain abstraction | 2026 SNP satisficing/agile 우승 및 optimal abstraction baseline |
| 6 | TamerLite | 모듈형 Python/Rust heuristic search | custom heuristic 실험과 UP 통합에 유리 |
| 7 | Metric-FF | Numeric RPG | 역사적이지만 반드시 필요한 relaxation 기준점 |
| 8 | OMTPlan | SMT/OMT | state-dependent cost와 optimal symbolic baseline |
| 9 | OPTIC / POPF / COLIN | Temporal forward search + LP | temporal·continuous linear numeric 확장 기준점 |
| 10 | SMTPlan+ / DiNo / UPMurphi | PDDL+ | process/event/nonlinear 후속 확장 기준점 |

### 2026 Numeric IPC가 보여준 현재 지형

2026 Numeric IPC는 SNP와 LNP를 optimal, satisficing, agile로 나눴고 10개 planner
team의 frozen source를 공개했다. 전체 optimal winner는 Tyr, 전체
satisficing/agile winner는 Panino, SNP satisficing/agile winner는 Count Downward,
SNP optimal winner는 Count Downward Together였다. 이 결과 때문에 2023년까지의
`ENHSP vs NLM-CutPlan vs OMTPlan`만으로는 현재 baseline landscape를 대표할 수
없다.

공식 결과와 source: [IPC 2026 Numeric Tracks](https://ipc2026-numeric.github.io/)
