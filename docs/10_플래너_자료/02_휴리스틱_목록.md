# 수치 플래닝의 수학적·탐색 휴리스틱 목록

LLM/학습 기반 방법을 제외하고, 구현 또는 비교할 가치가 있는 heuristic과 search
mechanism을 정리한다. 동일 이름이라도 planner마다 세부 semantics가 다르므로 논문명과
구현 configuration을 함께 고정해야 한다.

## 1. Relaxed planning graph 계열

### Numeric RPG / Metric-FF

- Boolean delete effect와 numeric harmful effect를 완화한다.
- Monotonicity transformation 뒤 reachable numeric bound를 layer별로 전파한다.
- Relaxed plan cost/length와 helpful action을 추출한다.
- 장점: 매우 빠르고 역사적으로 강함.
- 손실: resource consumption, mutex, negative interaction, packing/grouping.
- 원문: [Hoffmann 2003](https://arxiv.org/abs/1106.5271)

### Interval-based relaxation

- 각 numeric variable의 reachable value를 interval로 전파한다.
- General nonlinear expression과 cyclic dependency까지 확장 가능하다.
- 변수 간 correlation을 독립 interval로 풀어버릴 수 있다.
- 원문: [Scala et al. 2016](https://users.cecs.anu.edu.au/~thiebaux/papers/ecai16.pdf)

### Asymptotic Interval-Based Relaxation(AIBR/ARPG)

- 반복 action에 따른 asymptotic reachability를 분석한다.
- ENHSP와 PATTY의 pattern construction에서 중요한 기반이다.
- 반복 횟수와 실제 finite ordering을 동일하게 해결하는 것은 아니다.

### Effect-abstraction relaxation

- Linear state-dependent effect를 더 단순한 효과로 abstraction해 reachability를 구한다.
- Constant-effect relaxation보다 coupling 표현력이 높지만 abstraction loss가 남는다.
- 원문: [Li et al. 2018](https://www.ijcai.org/proceedings/2018/665)

### Relaxed-plan supporter multiplicity

- Numeric subgoal을 만족시키려면 supporter action이 몇 번 필요한지 계산한다.
- Tempest Numeric의 supporter/effect multiplicity와 ENHSP multi-repetition을 비교한다.
- Capacity benchmark에서는 action count와 object instantiation/grouping의 차이를 측정한다.

## 2. Numeric subgoaling 계열

### Atomic subgoaling `hadd` / `hmax`

- Numeric condition을 regression하여 possible achiever와 필요 조건을 계산한다.
- `hadd`는 subgoal 비용을 더하고 `hmax`는 최대를 취한다.
- Multi-variable condition의 internal negative interaction을 Metric-FF보다 잘 다룰 수 있다.
- Atomic decomposition 때문에 goal 간 resource sharing/order는 약화될 수 있다.
- 원문: [Heuristics for Numeric Planning via Subgoaling](https://www.ijcai.org/Proceedings/16/Papers/457.pdf)

### Conjunctive/generalized subgoaling

- Atomic subgoal을 독립화하지 않고 conjunction을 더 직접 다룬다.
- LP/MIP를 결합해 stronger bound를 만들 수 있다.
- 계산비용과 informedness trade-off를 반드시 evaluation time과 함께 측정한다.
- 원문: [Scala et al. JAIR 2020](https://www.jair.org/index.php/jair/article/view/11875)

### Multi-repetition relaxed plan(MRP)

- relaxed plan의 action마다 반복 횟수를 붙인다.
- heuristic value뿐 아니라 helpful action과 jumping action을 만든다.
- 현재 package grouping 연구에서 `몇 번`과 `어떤 ground action/순서`의 차이를
  분석하기 좋은 baseline이다.

### Helpful actions / Up-to-jumping actions

- relaxed plan 또는 numeric subgoal에서 즉시 유망한 action을 preferred set으로 만든다.
- Jumping은 동일/관련 action 반복을 search에서 압축한다.
- 완전성을 유지하려면 non-preferred action을 fallback에서 제거하지 않아야 한다.
- 원문: [Scala et al. ICAPS 2020](https://ojs.aaai.org/index.php/ICAPS/article/view/6665)

### Lazy GBFS with numeric subgoaling

- heuristic evaluation을 expansion 시점까지 미루고 helpful/jumping successor에 집중한다.
- heuristic 자체 개선과 search schema 개선을 분리해 ablation해야 한다.
- 원문: [Scala & Bonassi 2025](https://ojs.aaai.org/index.php/ICAPS/article/view/36125)

## 3. LP/MIP resource-flow heuristic

### LP-RPG

- RPG에 producer-consumer resource balance LP를 결합한다.
- 소비된 resource를 relaxation이 재사용하는 오류를 줄인다.
- Temporal/numeric fact layer와 LP의 결합 위치, LP 호출 횟수가 핵심이다.
- 원문: [Coles et al. Hybrid LP-RPG](https://arxiv.org/abs/1402.0564)

### Action-count LP/IP heuristic

- action 실행 횟수 `y_a`를 변수로 두고 goal/resource equation을 만족하는 최소 비용을 푼다.
- LP는 fractional count 때문에 싸지만 약할 수 있고, IP는 강하지만 비싸다.
- Action ordering과 ground-object grouping은 count만으로 완전히 복구되지 않는다.
- 원문: [Piacentini et al. 2018](https://ojs.aaai.org/index.php/AAAI/article/view/12082)

### Operator-counting constraints

- State equation constraint
- Numeric state equation constraint
- Delete-relaxation constraint
- Landmark constraint
- Inverse/relevance/temporal constraint
- Numeric LM-cut constraint
- 여러 constraint generator를 LP/IP objective에 누적한다.

### MILP heuristic versus full MILP compilation

- Heuristic: search state마다 relaxed remaining-cost MILP를 푼다.
- Compilation: plan horizon 전체의 action/state/order를 하나의 MILP로 푼다.
- 동일한 LP/MILP라는 이유로 같은 방법으로 분류하면 안 된다.

## 4. Landmark와 cut 계열

### Numeric landmarks

- 모든 valid plan이 통과해야 할 numeric region/action을 찾는다.
- LP로 landmark cost를 결합할 수 있다.
- Shared resource의 necessity는 잡아도 object-level optimal grouping까지 보장하지 않는다.
- 원문: [Scala et al. 2017](https://www.ijcai.org/proceedings/2017/612)

### Numeric `hmax`

- Numeric/propositional subgoal 중 가장 비싼 achiever chain을 lower bound로 사용한다.
- Simple numeric fragment에서 admissible configuration의 기반이다.

### Numeric LM-cut family

- Simple numeric condition용 LM-cut
- `hLM-cut_cri`, interval-relaxation variant, multi-achiever variant
- second-order simple effect와 bound-enhanced `2b`, `2b+`
- Linear numeric effect/conditional effect extension
- 원문: [LM-cut and Operator Counting for Numeric Planning](https://ojs.aaai.org/index.php/ICAPS/article/view/15964),
  [Linear Numeric LM-cut](https://ojs.aaai.org/index.php/ICAPS/article/view/19803)
- 구현: Numeric Fast Downward, PlanForge, Count Downward portfolios

### Numeric bound extraction

- Numeric variable의 reachable lower/upper bound를 추출해 LM-cut과 encoding을 강화한다.
- Unbounded와 bounded benchmark를 구분하는 데도 활용 가능하다.

### Symmetry / Orbit-space search

- Numeric problem description graph의 automorphism으로 symmetric state를 canonicalize한다.
- Heuristic이 아니라 sound pruning/search reduction mechanism이다.
- 2023 NLM-CutPlan Orbit과 2026 Count Downward Together의 핵심 구성 요소.

## 5. Abstraction heuristic

### Numeric Pattern Database(PDB)

- 일부 propositional/numeric variable에 projection하고 abstract exact cost를 계산한다.
- Numeric projection은 대개 infinite이므로 finite reachable fragment와 fringe backup이 필요하다.
- 원문: [Gnad et al. 2025](https://ojs.aaai.org/index.php/AAAI/article/view/34851)

### Infinite-abstraction handling

- Blind fringe backup의 무정보성 문제를 분석한다.
- failed lookup, goal-directed/LM-cut-informed backup 등으로 PDB 정보성을 높인다.
- 원문: [Fritzsche et al. 2026](https://ojs.aaai.org/index.php/AAAI/article/view/40941)

### Domain abstraction + CEGAR

- Numeric domain을 interval block으로 나누고 counterexample에 따라 refine한다.
- Infinite concrete space 전체를 finite abstract interval partition으로 대표한다.
- 여러 abstraction은 canonical heuristic으로 admissibly 결합한다.
- 원문: [Domain-Abstraction Heuristics](https://doi.org/10.5281/zenodo.20424990)

### Cartesian abstraction + CEGAR

- 각 abstract state가 numeric variable별 하나의 interval을 갖는 Cartesian state다.
- Spurious abstract plan의 flaw를 따라 interval을 refine한다.
- Positive-cost simple numeric task에서 semi-completeness/optimality 결과가 있다.
- 원문: [Schindler, Speck, Helmert 2026](https://ai.dmi.unibas.ch/papers/schindler-et-al-icaps2026.pdf)
- artifact: [Zenodo 18999077](https://zenodo.org/records/18999077)

### Canonical combination과 cost partitioning

- 서로 additive한 abstraction 집합을 canonical heuristic으로 결합한다.
- 단순 합은 action cost를 중복 계산할 수 있으므로 admissibility를 깨뜨릴 수 있다.
- Count Downward 계열에서 numeric PDB/domain abstraction 결합을 확인한다.

## 6. Novelty, width, distance, dominance

### Numeric novelty

- Boolean feature의 first achievement와 numeric feature의 best distance improvement를 추적한다.
- Partitioned novelty는 같은 base-heuristic partition 안에서 novelty를 계산한다.
- 2024 multi-queue 연구와 2026 Panino 구현을 구분한다.
- 원문: [Chen & Thiébaux 2024](https://arxiv.org/abs/2404.05235),
  [Panino abstract](https://ipc2026-numeric.github.io/abstracts/team-3.pdf)

### Manhattan numeric distance

- Numeric subgoal의 normalized violation distance를 집계한다.
- 값은 싸지만 action reachability/cost와 직접 일치하지 않을 수 있다.

### Multi-queue and portfolio

- `hadd`, novelty, distance, preferred queue 등을 서로 다른 open list로 결합한다.
- 단일 scalar mix보다 scale tuning에 덜 민감할 수 있다.
- Queue scheduling 자체가 결과에 기여하므로 heuristic 단독 비교가 필요하다.

### Numeric state dominance

- Boolean 부분이 같고 모든 monotonic-good numeric variable에서 한 state가 더 좋으면
  열등한 state를 sound하게 prune할 수 있다.
- equality, conflicting direction, nonlinear use가 있으면 보수적으로 must-match 처리한다.
- nplanning의 monotonicity/dominance 구현이 현대 비교점이다.

## 7. Temporal-numeric heuristic/scheduling

### Temporal RPG / context-enhanced additive heuristic

- Proposition과 numeric fluent의 도달 시간/비용을 temporal layer에서 전파한다.
- SAPA와 TFD가 서로 다른 방식으로 cost와 makespan guidance를 구성한다.

### STN + LP consistency

- Temporal ordering은 STN, continuous numeric relation은 LP로 관리한다.
- CRIKEY→COLIN→POPF→OPTIC 계보에서 발전했다.
- Heuristic estimate와 schedule feasibility LP를 구분해 측정해야 한다.

### Partial-order lifting

- Action start time을 즉시 고정하지 않고 현재 plan prefix가 허용하는 partial order를 유지한다.
- POPF/OPTIC의 핵심이며 concurrency와 makespan quality에 중요하다.

### Lazy LP consistency checking

- 모든 successor에서 완전 LP check를 하지 않고 필요할 때까지 consistency 검사를 지연한다.
- Piecewise-linear continuous effect에서 evaluation overhead를 낮춘다.
- 원문: [Bajada et al. 2021](https://arxiv.org/abs/2105.10176)

### Planning-graph local search

- Complete state-space traversal 대신 temporal action graph의 flaw를 stochastic local search로 수정한다.
- LPG/LPG-td의 핵심으로 anytime quality baseline에 적합하다.

## 8. SAT/SMT/OMT/MILP/CP encoding 기법

### Horizon-based SAT/SMT

- Plan length/happening bound `k`를 정하고 transition formula를 푼다.
- 실패하면 bound를 증가시킨다.
- Long plan에서는 encoding size와 horizon이 병목이다.

### Rolled-up action encoding

- 같은 action의 반복 횟수를 integer/real variable 하나로 압축한다.
- Counters/resource accumulation에는 강하지만 arbitrary ordering에는 추가 encoding이 필요하다.
- SpringRoll이 대표 구현이다.

### Relaxed exists-step / R2-exists encoding

- 서로 간섭하지 않는 action을 한 symbolic step에 넣어 horizon을 줄인다.
- Syntactic/semantic interference test의 강도와 SMT formula 크기가 trade-off다.

### Symbolic Pattern Planning

- 임의 action 선택 대신 미리 구성한 action pattern의 subsequence/repetition을 SMT로 푼다.
- Static pattern, dynamic pattern, brave/greedy extension이 있다.
- PATTY/PATTINT/PATTY Temporal이 대표다.

### OMT planning

- Feasibility SMT에 cost minimization을 직접 결합한다.
- State-dependent action cost를 encoding하기 좋다.
- OMT solver overhead가 unit-cost task에서는 손해일 수 있다.

### Full MILP compilation

- Horizon별 action selection, state transition, numeric constraint, ordering, cost를 MILP로 푼다.
- Branch-and-cut, landmark/relevance cut으로 강화할 수 있다.
- 원문: [Piacentini et al. 2018](https://ojs.aaai.org/index.php/ICAPS/article/view/13919)

### Constraint programming / chronicles

- Optional action instance와 condition/effect token을 CP variable/constraint로 표현한다.
- Clause learning과 temporal/numeric propagator를 결합한다.
- Aries가 대표적 현대 구현이다.

### Classical bit-blast compilation

- Bounded integer numeric variable을 one-hot 또는 binary Boolean facts로 encode한다.
- Native numeric heuristic과 classical LAMA heuristic의 장단점을 직접 비교할 수 있다.
- 원문/code: [BitBlast](https://github.com/LBonassi95/BitBlast)

## 9. PDDL+ heuristic/solution techniques

### Discretise and validate

- Time/numeric domain을 일정 step으로 discretise해 finite search한 뒤 원래 continuous model에서 validate한다.
- UPMurphi는 blind, DiNo는 SRPG+ informed search를 사용한다.
- Discretisation resolution에 따른 incompleteness/비용을 보고해야 한다.

### Staged Relaxed Planning Graph Plus(SRPG+)

- Process/event와 시간 진행을 포함한 relaxed reachability stage를 만든다.
- Time passing 자체를 helpful action으로 판단해 idle-step explosion을 줄인다.
- 구현: DiNo.

### PDDL+ to SMT

- Continuous time과 process/event constraint를 SMT theory로 직접 encoding한다.
- SMTPlan+는 Z3 기반; dReal 계열은 nonlinear delta-SMT를 사용한다.

### PDDL+ to CASP

- Logical choice는 ASP, numeric/continuous constraint는 constraint solver에 맡긴다.
- SMT와 다른 propagation/search behavior의 대조군이다.

### Lifted search + nonlinear programming

- Action schema를 ground하지 않고 symbolic time/numeric parameter를 NLP solver로 검사한다.
- NEAT가 연구 prototype이며, per-step NLP overhead와 수작업 translation이 주요 변수다.

## 10. 현재 capacity/grouping 연구의 최소 heuristic set

1. Blind/goal count
2. Metric-FF numeric RPG
3. ENHSP `hadd`
4. ENHSP `hmax`
5. ENHSP multi-repetition relaxed plan
6. Helpful action
7. Up-to-jumping/lazy GBFS variant
8. LP-RPG resource flow
9. Numeric LM-cut
10. Operator counting LP/IP
11. Numeric PDB 또는 domain abstraction
12. Numeric novelty/Panino
13. Numeric state dominance on/off
14. Handcrafted aggregate-weight lower bound
15. Exact bin-packing lower bound/oracle
16. PATTY symbolic pattern planning
17. OMTPlan
18. BitBlast + LAMA

이 18개를 모두 처음부터 실행할 필요는 없다. 그러나 논문의 related work와
baseline exclusion rationale에는 전부 등장해야 한다.
