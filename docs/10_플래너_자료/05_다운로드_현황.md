- 실행일: 2026-09-07
- 공개 Git source: **57 repositories**
- 원본 배포 파일: **64 archives/binaries**
- 저장 용량: Git source 약 **8.7 GiB**, archives 약 **183 MiB**
- 무결성 검사: **121개 checksum/revision 확인, 6개 raw binary의 container-format 검사만 생략, 0 failed**
- 실행 검사: **43개 YAML batch 구성**(42개 local VAL 검증 + 사용자 host에서 확인된 `popf-static-v2`), 1개 compiler 변환 성공

[06 다운로드 목록](06_다운로드_목록.md), 정확한 Git revision과 archive
checksum은 각각 `planners/locks/downloaded-revisions.tsv`와
`planners/locks/downloaded-archives.sha256`에 있다.

121개 전체 이름은 [07 확보 자료 보고서](07_확보_자료_보고서.md),
독립 실행 명령은 [03 실행 안내](03_실행_안내.md)에 정리했다.

  Tempest, temporal-planning suite, FAPE

- backend/infrastructure: Z3, Yices2, dReal4, CLP, CBC, SCIP, clingo,
  Unified Planning, planutils, VAL, Tarski, JPDDL+, PPMaJal

각 저장소는 현재 default branch를 shallow clone했고, 실제 40자리 commit을 lock에
기록했다. recursive submodule이 필요한 저장소는 clone 시 함께 받았다.

## 공개 URL에서 실패한 항목

| ID | 결과 | 확인 내용 |
|---|---|---|
| `numce-compiler` | GitHub 404 | 문헌의 `Plutone/numce-compiler`가 삭제되었고 GitHub 공개 검색에서도 mirror를 찾지 못함 |
| `temporal-ipc2018-team3` | clone 실패 | IPC-2018 Bitbucket team repository가 현재 공개 clone 불가 |
| `tlplan-scheme` | HTTP 404 | 공식 페이지의 `tlplan.scm.tar` 링크가 깨졌고 Wayback CDX에도 보존본 없음 |
| `cpt-linux-sparc` | HTTP 404 | 공식 페이지 링크는 남아 있으나 파일이 삭제됐고 Wayback CDX에도 보존본 없음 |

위 네 항목은 자동화 오류가 아니라 upstream artifact 부재다. 실패 내역은
`planners/download-logs/fetch-status.tsv`와 `archive-status.tsv`에 유지한다.

## 자동으로 받을 수 없는 항목

- LPG 1.2/LPG-td 일부 배포와 TAMER: 사용자 등록 및 배포 조건 동의 필요
- CPLEX, Gurobi, MathSAT, OptiMathSAT: 계정 또는 연구/상용 라이선스 필요
- ENHSP 2018/2019/2020 Singularity Hub images: 기존 `shub://` 서비스 종료
- Nyx, NEAT, TM-LPSAT, dReal PDDL+ encoder, Kongming, piecewise-linear
  Tempest/OPTIC++: 검증된 공개 구현 URL 없음
- SemSyn, original MIPS/SGPlan 4·5, standalone ITSAT/YAHSP: 공개 원본을 추가 추적해야 함

라이선스/등록 장벽을 우회하거나 상용 binary를 재배포하지 않는다.

## 재실행과 검증

```bash
bash scripts/fetch_numeric_planners.sh
bash scripts/fetch_numeric_archives.sh
bash scripts/verify_numeric_downloads.sh
```

다운로드 스크립트는 이미 존재하는 정상 파일/저장소를 건너뛴다. 검증 스크립트는
archive SHA-256, gzip/bzip2/tar/zip/JAR/whl 컨테이너, Git HEAD와 lock revision을
검사한다. 다운로드 로그와 대용량 artifact는 `.gitignore` 처리되어 있다.
