# 수치 플래너 다운로드 목록

- 조사 기준일: 2026-09-07
- 목적: 우선순위와 무관하게 입수 가능한 numeric/temporal-numeric/PDDL+ planner,
  competition snapshot, adapter, backend, benchmark를 모두 보존하기 위한 전수 목록
- 원칙: 같은 이름이라도 maintained source, 논문 artifact, IPC frozen source가 다르면
  서로 다른 다운로드 대상으로 취급한다.

이 문서는 설치 성공 목록이 아니라 **다운로드 큐**다. 링크가 존재해도 라이선스,
32-bit 의존성, 오래된 compiler, 상용 solver 요구사항 때문에 바로 실행되지 않을 수 있다.

## 상태 표기

| 표기 | 의미 |
|---|---|
| `GIT` | Git 저장소 전체를 clone하고 정확한 commit을 고정 |
| `ARCHIVE` | tar/zip 등 원본 파일을 내려받아 SHA-256 고정 |
| `IPC` | 대회 당시 frozen source 또는 container snapshot |
| `BIN` | 소스 없이 실행 파일/JAR/image만 입수 가능 |
| `REG` | 등록, 연구용 허가 또는 별도 라이선스가 필요 |
| `POINTER` | 다운로드 안내는 있으나 직접 artifact를 추가 확인해야 함 |
| `MISSING` | 공개 구현을 확인하지 못했으므로 자동 다운로드 금지 |

다운로드 완료 표시는 각 행의 `[ ]`를 `[x]`로 바꾸되, 파일이 존재한다는 이유만으로
완료 처리하지 않는다. URL, revision/SHA-256, license, 압축 해제 성공까지 기록해야 한다.

## 7. 현재 공개 다운로드를 확인하지 못한 항목

다음은 문헌 카탈로그에는 유지하지만, 검증된 공개 source URL이 생기기 전까지
다운로드 완료로 표시하지 않는다.

| 항목 | 현재 상태 | 필요한 후속 확인 |
|---|---|---|
| SemSyn | IPC3 결과/논문만 확인 | 저자 또는 IPC3 submission archive |
| original TP4 release | HSP-star 계보 자료는 있음 | TP4 정확한 release filename/semantics |
| original MIPS | IPC-2008 MIPS-XXL snapshot은 있음 | Freiburg historical source mirror |
| original SGPlan 4/5 | SGPlan6 IPC snapshot은 있음 | IPC4/IPC5 source archive |
| ANMLSMT | TAMER 계보와 논문 비교 대상 | 독립 배포인지 TAMER release 내부 engine인지 확인 |
| ITSAT standalone | IPC-2018 portfolio image에는 포함 | standalone source/license 확인 |
| YAHSP2/YAHSP3 standalone | IPC-2018 portfolio image에는 포함 | 원본 source/license 확인 |
| Nyx | 논문만 확인 | 저자 source repository 요청 |
| NEAT | 논문만 확인 | HTSC translator와 CLP code 요청 |
| TM-LPSAT | 논문만 확인 | original compiler와 LPSAT runtime 추적 |

| Kongming | 역사적 논문 언급 | 저자/기관 archive 추적 |
| piecewise-linear Tempest/OPTIC++ | 논문만 확인 | 2021 experiment source 요청 |

## 8. 다운로드 완료 조건

각 행은 다음 파일이 모두 생겨야 완료다.

```text
planners/registry/<id>.yaml
planners/external/<id>/source/       # 또는 artifact 원본
planners/locks/<id>.lock.yaml
planners/licenses/<id>/LICENSE.txt   # 없으면 LICENSE-STATUS.md
planners/checksums/<id>.sha256
```

`<id>.lock.yaml`에는 다음 필드를 강제한다.

```yaml
id: optic-maintained
retrieved_at: "2026-09-07T00:00:00+09:00"
source_type: git
source_url: https://github.com/KavrakiLab/optic
revision: "<40-character-commit>"
archive_sha256: null
recursive_submodules: true
license_status: pending-review
download_status: fetched
unpack_status: passed
build_status: untested
smoke_test_status: untested
```

## 9. 반드시 별개로 보존할 중복 버전

중복처럼 보여도 다음은 합치지 않는다.

- ENHSP maintained source와 ENHSP 2018/2019/2020 JAR
- Numeric Fast Downward maintained source와 IPC 2023 LNM-Plan snapshot
- OMTPlan maintained source와 IPC 2023 snapshot
- PATTY maintained source와 IPC 2026 snapshot
- TamerLite maintained/PyPI/IPC 2026 snapshot
- PlanForge maintained source와 IPC 2026 snapshot
- OPTIC modern fork, alternate fork, SourceForge original/patched releases
- POPF maintained fork와 SourceForge archive
- TFD Git mirror와 IPC-2008 snapshot
- LPG 1.2 source, LPG-td executable, planutils package
- SGPlan6 sequential, fixed sequential, temporal/numeric snapshot
- MIPS-XXL sequential-optimal과 numeric net-benefit snapshot

이 버전들은 알고리즘 이름은 같아도 parser, dependency, configuration, bug fix와
competition behavior가 다르기 때문에 각각 독립적인 실험 대상이다.
