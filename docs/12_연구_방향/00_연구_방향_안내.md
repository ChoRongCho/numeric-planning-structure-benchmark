# 연구 방향 안내

이 폴더는 검증된 결론이 아니라, 현재까지의 이론과 실험 관찰을 바탕으로 발전시킬
연구 가설, 방법론 후보, 검증 계획을 관리한다.

1. [수치 플래닝 휴리스틱 연구 방향](01_수치_플래닝_휴리스틱_연구_방향.md):
   numeric relaxation에서 약해지는 구조를 분석하고 interaction potential과
   domain-semantic guidance를 후보 방법론으로 정의한다.
2. [미래 수치 충돌을 위한 잠재함수 기반 메타휴리스틱 연구보고서](02_미래_수치_충돌을_위한_잠재함수_기반_메타휴리스틱_연구보고서.pdf):
   delayed numeric conflict 문제, 기존 휴리스틱의 시간–정보량 trade-off,
   state-level feasibility prior와 단계별 검증 구조를 하나의 연구 흐름으로 정리한다.
3. [연구보고서의 논문 주제 평가](03_연구보고서_논문주제_평가.md):
   기존 heuristic selection 연구와의 차별성, 현재 설계의 위험, 한 편의 논문으로
   좁힌 연구 질문과 Go/No-Go 실험을 정리한다.

[연구 가설 후보](../03_연구_가설_후보.md)는 먼저 검증해야 할 실패 원인을 관리하고,
이 폴더는 그 원인이 확인됐을 때 평가할 해결 방향을 구체화한다. 두 문서의 가설과
결론을 혼동하지 않는다.
