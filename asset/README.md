# External assets

외부 기관 전달 자료와 회의 자료의 원본 보관 위치입니다. 파일명과 내용은 provenance 유지를 위해 변경하지 않습니다.

- `00_Document/`: 메모, 이메일 대화, 과제·회의·발표 PDF 원본
- `01_Code/`: 연세대 제공 TSD prompt, schema, 68개 sample과 전달 archive
- `02_PPTs/`: 과제·회의·발표 PPTX 원본
- `03_Paper/`: 연구 주제, 논문 기획 및 문헌조사 초안
- `03_Paper/`: 연구 및 과제 관련 논문 자료

실험 코드는 TSD 프로토콜의 canonical 위치로 `asset/01_Code/task_situation_description_samples/`를 사용합니다.

Git에는 테스트와 프로토콜 검토에 필요한 `01_Code/task_situation_description_samples/`만 포함합니다. 이메일, PDF, PPTX 원본은 용량·개인정보·외부 자료 공개 범위를 고려해 로컬에만 보관하며, 별도 공개 허가 없이 public 저장소에 올리지 않습니다.
