# 연구 주제 초안

이 폴더는 RoboCasa 기반 로봇 작업 계획과 소형 언어모델을 이용한 classical planning 연구 아이디어를 정리하는 공간이다.

## 문서

- `slm_admissible_potential_heuristic_research_idea.md`: SLM이 상태 feature를 제안하고 symbolic optimization이 admissible potential heuristic을 구성하는 연구 아이디어
- `numeric_aware_slm_subgoal_planning_report.md`: 토론 내용을 종합한 numeric-aware SLM subgoal planning 연구 기획 보고서
- `three_numeric_aware_search_guidance_directions.md`: heuristic mapper, subgoal decomposer, preferred action의 세 연구 후보 비교 및 우선 방향 선정 보고서
- `llm_heuristic_numeric_planning_baseline_review.md`: LLM 기반 classical-planning search guidance와 numeric-planning heuristic 문헌 조사, 1차 baseline 선정 보고서
- `numeric_planning_foundations_and_research_reframing.md`: classical numeric planning의 기본 구조와 numeric-aware heuristic을 정리하고 LLM의 연구 공백을 재정의한 보고서
- `numeric_planning_failure_modes_and_research_hypothesis.md`: numeric planner의 실패 의미를 구분하고 numeric-symbolic coupling, relaxation 정보 손실 및 search 성능 저하에 관한 검증 가설을 정리한 보고서
- `classical_numeric_planning/`: classical numeric planning의 정의, relaxation, subgoaling, LP/IP, optimal heuristic, SMT/MILP, search control 및 learning 관련 핵심 논문 25편과 분야 지도
- `llm_planning_papers/`: LLM planning 관련 논문 링크와 다운로드 목록
- `review/`: 수집 논문의 개별 리뷰와 종합 리뷰 자료

현재 문서는 1차 토론 결과이며, 관련 연구 전수 조사와 실험 가능성 검토 전의 가설을 포함한다.
