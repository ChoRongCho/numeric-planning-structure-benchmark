# Experiments

실험 하나는 하나의 반증 가능한 질문을 다룹니다. 디렉터리는
`NNN_<short_name>` 형식으로 만들고 `_template/`에서 시작합니다.

초기 실험 후보:

1. `000_sanity`: planner wrapper와 metric 검증
2. `001_size_scaling`: 순수 problem size 효과
3. `002_capacity_tightness`: capacity slack 변화
4. `003_coupling`: symbolic choice/resource coupling 변화
5. `004_handcrafted_heuristic`: capacity-aware baseline 비교
